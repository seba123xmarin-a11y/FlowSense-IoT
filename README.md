
FlowSense IoT: plataforma web en Django para monitorear y controlar en tiempo real una planta de flujo conectada a un PLC Siemens S7-1200, junto con sensores en una ESP32 (infrarrojo) y una Raspberry Pi, comunicados vía MQTT.
